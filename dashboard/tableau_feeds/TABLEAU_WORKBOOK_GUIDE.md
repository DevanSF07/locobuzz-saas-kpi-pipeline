# Tableau Executive Dashboard Implementation Guide
### LocoBuzz Solutions | AI Product Manager Intern Portfolio

This guide details how to build and publish the **Executive SaaS Intelligence & Cohort Dashboard** in **Tableau Desktop** or **Tableau Public** using the pre-aggregated SQL feeds generated by our Postgres ETL pipeline.

---

## 1. Data Sources Overview

The pipeline exports three production-ready CSV feeds to `/dashboard/tableau_feeds/`:

| File Name | Description | Key Dimensions & Measures |
| :--- | :--- | :--- |
| `tableau_saas_kpi_feed.csv` | Monthly SaaS Financials & Core KPIs | `billing_month`, `total_mrr`, `new_mrr`, `expansion_mrr`, `contraction_mrr`, `churned_mrr`, `logo_churn_rate`, `nrr_percentage`, `saas_quick_ratio`, `avg_ltv`, `avg_cac` |
| `tableau_cohort_retention_feed.csv` | Cohort Retention Matrix | `cohort_month`, `tenure_month`, `plan_tier`, `experiment_group`, `cohort_starting_accounts`, `active_accounts`, `retention_rate`, `churn_rate`, `arpu` |
| `tableau_pricing_gap_feed.csv` | Unit Economics & Pricing Gap Isolation | `billing_month`, `plan_tier`, `experiment_group`, `avg_tokens`, `avg_overage_charge`, `accounts_facing_pricing_gap` |

## 2. Tableau Calculated Fields Reference

Create the following calculated fields in Tableau:

### A. Net Revenue Retention (NRR %)
```tableau
// Calculated Field: [Net Revenue Retention Rate]
(([Starting MRR] + [Expansion MRR] - [Contraction MRR] - [Churned MRR]) / [Starting MRR]) * 100
```

### B. Logo Churn Rate %
```tableau
// Calculated Field: [Logo Churn %]
SUM([churned_accounts]) / SUM([starting_accounts])
```
*Format as Percentage with 1 decimal place.*

### C. SaaS Quick Ratio
```tableau
// Calculated Field: [SaaS Quick Ratio]
(SUM([new_mrr]) + SUM([expansion_mrr])) / (SUM([contraction_mrr]) + SUM([churned_mrr]))
```
*Format as Number (Standard) with 2 decimals (e.g. 2.54).*

### D. Cohort Color Divergence Scale (For Heatmap)
```tableau
// Calculated Field: [Retention Tier Group]
IF [retention_rate] >= 0.90 THEN "High Retention (>90%)"
ELSEIF [retention_rate] >= 0.80 THEN "Good Retention (80-90%)"
ELSEIF [retention_rate] >= 0.70 THEN "Moderate Retention (70-80%)"
ELSE "At Risk (<70%)"
END
```

## 3. Worksheets Setup

### Sheet 1: Executive KPI Header Banners (Scorecards)
1. Drag `Measure Values` to Text on the Marks card.
2. Filter `Measure Names` for:
   - `total_mrr`
   - `logo_churn_rate`
   - `nrr_percentage`
   - `ltv_cac_ratio`
   - `saas_quick_ratio`
3. Set Mark type to **Text**, arrange side-by-side horizontally.

### Sheet 2: MRR Waterfall & Revenue Trajectory
1. Columns: `billing_month` (Continuous or Date).
2. Rows: `total_mrr`, `new_mrr`, `churned_mrr`.
3. Mark Type: Dual-axis Line & Bar chart or Area chart.
4. Color scheme:
   - Total MRR: Sky Blue (`#38BDF8`)
   - New MRR: Emerald Green (`#10B981`)
   - Churned MRR: Rose Red (`#F43F5E`)

### Sheet 3: Cohort Retention Matrix Heatmap
1. Rows: `cohort_month` (Discrete).
2. Columns: `tenure_month` (Discrete: 0 through 11).
3. Marks: Set mark type to **Square**.
4. Color: Drag `retention_rate` to **Color**.
   - Edit Colors: Select **Green-Gold-Red Diverging** (Reversed).
   - Set Center at `0.80` (80%), Min at `0.50`, Max at `1.00`.
5. Label: Drag `retention_rate` to **Label** (Format as `0.0%`).

### Sheet 4: A/B Test Churn Reduction & Pricing Gap
1. Columns: `experiment_group` (`Control` vs `Variant`).
2. Rows: `AVG([churn_rate])`.
3. Filters: `plan_tier` = `Growth`.
4. Color: `experiment_group` (Control = Rose `#F43F5E`, Variant = Emerald `#10B981`).
5. Tooltip: Add Z-score (5.23), p-value (< 0.0001), and Annual ARR saved ($1.98M).

## 4. Assembling the Executive Dashboard Layout
1. Set Dashboard Canvas Size to **1400 x 900 px (Fixed Size)**.
2. Add Title Container with LocoBuzz branding and "Live 17K+ B2B Accounts Connected" status.
3. Place KPI scorecards along the top horizontal container.
4. Place **MRR Trajectory** (left) and **Pricing Gap Chart** (right) in a 50/50 split container.
5. Place **Cohort Retention Heatmap** across the bottom full-width container.
6. Add Quick Filters: `Plan Tier` and `Experiment Group`.
